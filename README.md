# Antic Mitra — "Automate the Impossible."

Official website for **Antic Mitra**, building advanced AI SaaS products, conversational WhatsApp chatbots, multilingual AI voice call agents, custom CRM pipelines, and hyper-targeted digital marketing automations.

## 🎨 Brand Guidelines
- **Primary Color:** `--violet` (`#7B3FF2`)
- **Secondary Color:** `--pink` (`#FF5C8A`)
- **Accents:** `--lime` (`#C6F432`), `--sky` (`#2EC5FF`), `--yellow` (`#FFC93C`)
- **Backgrounds:** `--cream` (`#FFFDF7`), `--white` (`#FFFFFF`)
- **Typography:** Headings in Poppins, body in Inter.
- **Rule:** Strictly zero dark, black, or grey backgrounds.

## 🚀 Pages
- `index.html` — Home (Hero, Live Simulators, ROI Calculator, Services, FAQ, Testimonials)
- `about.html` — About Us ("Antic" + "Mitra" Philosophy, Core Values, Tech Stack)
- `projects.html` — Projects & Case Studies with interactive filter tabs
- `blogs.html` — AI & Automation Journal with featured masterclass
- `contact.html` — Interactive Project Brief & Strategy Call booking

## 🛠️ Run Locally
```bash
node server.js
```
Then visit `http://localhost:3000/`.
